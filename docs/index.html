Frontier build · trialling Memora

What does this account actually owe us right now?

Six months of meeting notes for one B2B account. The budget changed three times, the go-live date twice, the signoff owner left and came back. Answering “what is true today” is not a search problem — it is a memory problem.

This page runs Memora, the harmonic memory representation Microsoft Research presented at ICML 2026, over that corpus — and puts it head-to-head with a conventional chunk-and-embed RAG baseline on the same notes, same embedder, same answering model.
